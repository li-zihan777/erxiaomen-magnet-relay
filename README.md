# 二校门冰箱贴漂流计划

清华团校六班第四组六位成员的约饭与冰箱贴接力页面。

## 在线能力

- 六人两两约饭，共 15 个不重复组合
- 六边形关系图与点亮进度
- 当前冰箱贴持有人和智能抽签
- 抽下一位每天全组限用一次，按北京时间每天 00:00 自动重置
- 约饭时间轴、故事与留言簿
- Supabase 云端共享状态
- 普通约饭、留言和撤回无需登录或口令，保留乐观锁冲突处理
- 重置整个计划或用 JSON 覆盖导入时需要计划管理密码

## 隐私与安全

这是公开的 GitHub Pages 网站，页面内容和共享记录可被访问网站的人查看，任何访问者也可以提交约饭、留言或撤回最新记录。普通更新接口只允许新增一顿饭、新增一条留言或撤回最后一顿饭；整份状态替换必须通过服务端校验计划管理密码。数据库拒绝匿名直接修改表，仓库和网页均不包含管理密码、数据库管理密钥或数据库密码。
